# Contributing

Thank you for helping improve the Handshake Rust ecosystem.

Before opening a substantial pull request, describe the intended behavior,
compatibility boundary, and validation approach in an issue or discussion.
Consensus-sensitive changes should include fixtures or differential evidence,
while performance changes should include reproducible measurements.

Keep changes focused, preserve unrelated work, and document any behavior that
intentionally differs from existing Handshake implementations. Repository-local
contribution instructions take precedence over this organization default.
