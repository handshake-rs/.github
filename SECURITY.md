# Security Policy

Consensus, wallet, mining, update, and networking defects may place users or
funds at risk. Please do not disclose a suspected vulnerability in a public
issue.

Use the affected repository's **Security** tab and select **Report a
vulnerability**. Include the affected revision, impact, reproduction steps, and
any proposed mitigation. If private vulnerability reporting is unavailable,
contact an organization owner privately before sharing technical details.

Each released project may publish a more specific support window and response
policy. A repository-local policy takes precedence over this organization
default.
