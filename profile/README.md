# Handshake Rust Ecosystem

`handshake-rs` is an independent, community-led effort to build reliable Rust
infrastructure and applications for the Handshake ecosystem.

The work is organized around:

- reusable protocol and consensus libraries;
- a production-grade Handshake full node;
- decentralized CPU, GPU, and ASIC mining through MeshMine;
- DANE resolution and browser integration;
- reproducible cross-project audits and qualification.

Correctness is established with explicit compatibility fixtures, state
manifests, adversarial tests, and mainnet qualification. Compatibility with
existing Handshake software is evidence to verify, not a permanent runtime
dependency.

The organization is currently being assembled. Projects will move here only
after their ownership, licensing, release boundaries, and security policies are
documented.

Start with the [ecosystem coordination repository](https://github.com/handshake-rs/ecosystem).

> This is an independent project and does not claim to be the official
> Handshake organization.
